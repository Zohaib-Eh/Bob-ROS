# Frontend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A local web app that takes a CAD/mesh assembly through import, part fixes, link grouping, automatic joint suggestions, joint review with motion preview, and URDF export — with undo/redo and save/open.

**Architecture:** Vite + React + TypeScript for panels; plain three.js in one viewer module. All model logic lives in pure, unit-tested modules under `src/model/` (reducer, history, tree direction, touching pairs, detection queue, error mapping, project files). The backend gains two add-only endpoints (`/detect-joints` with body lists, `/link-mass`). The dev server proxies `/api/*` to the backend.

**Tech Stack:** Node 22, React 18, three 0.169, Vite 5, TypeScript 5, Vitest 2 + jsdom + Testing Library, Playwright; backend Python 3.11 conda env `cad-to-urdf`, FastAPI, pytest.

**Spec:** `docs/superpowers/specs/2026-10-08-frontend-design.md`

## Global Constraints

- Local only: backend `http://localhost:8000`, frontend dev server `http://localhost:5173`; the browser only calls `/api/...` (Vite proxy strips `/api`).
- The frontend holds no CAD or joint-inference logic: geometry is limited to drawing meshes, bounding boxes for the touching-pairs pre-check, and the motion-preview transform.
- Backend changes are add-only; existing request/response shapes keep working.
- Link names must match `^[A-Za-z0-9_][A-Za-z0-9_-]*$` and be unique.
- Contact tolerance for the touching-pairs pre-check is `1e-4` m (the backend's).
- Detection runs one request at a time.
- Undo history cap: 100 steps. Detection results (`setSuggestion`) are not history steps.
- Project file: `{"format": "cad-to-urdf-project", "version": 1, "model": ...}`; any other format/version is rejected without changing state.
- Every failed request shows a visible message.
- Backend tests: `cd backend && ~/miniforge3/envs/cad-to-urdf/python.exe -m pytest -q` (set `OPENBLAS_NUM_THREADS=1` for ad-hoc Python). Frontend tests: `cd frontend && npm test` (Vitest), `npm run e2e` (Playwright).
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

- **Merging links while a detection request is running** — the running request for the changed pair must be aborted and its stale result never stored; covered in Task 6 (`aborts the running pair when its membership changes`).
- **Undo after a merge that dropped joints** — undo must restore the links *and* the joints; covered in Task 5 (`undo restores joints dropped by a merge`).
- **Opening a corrupt or foreign JSON file as a project** — error message, state unchanged; covered in Task 5 (`rejects non-JSON and foreign files`).
- **Export with an invalid tree** (two disconnected groups) — Export disabled with the reason; never a request that fails late; covered in Task 4 (`flags links not connected to the base`) and Task 11 (`buildExportRequest returns errors for a disconnected tree`).
- **Part names that aren't valid link names** (STEP product names like `IRB1300_7_12KG-1400 IP40 (1)`, duplicates) — default link names are sanitized and de-duplicated; covered in Task 3 (`sanitizes and de-duplicates link names`).

`frontend/src/api/client.ts`:

```ts
import type { Body, DetectResponse, ImportResponse, Joint, Link, LinkMass, PartWarning, Vec3 } from "./types";

export class ApiError extends Error {
  constructor(public status: number, message: string) {
    super(message);
  }
}

export function errorText(detail: unknown): string {
  if (typeof detail === "string") return detail;
  if (Array.isArray(detail)) {
    return detail.map((d: { loc?: unknown[]; msg?: string }) =>
      `${(d.loc ?? []).join(".")}: ${d.msg ?? ""}`).join("; ");
  }
  return "Request failed";
}

async function send(path: string, init: RequestInit): Promise<Response> {
  let res: Response;
  try {
    res = await fetch(`/api${path}`, init);
  } catch (e) {
    if ((e as Error).name === "AbortError") throw e;
    throw new ApiError(0, "Cannot reach the backend — is it running on localhost:8000?");
  }
  if (!res.ok) {
    let detail: unknown = res.statusText;
    try { detail = (await res.json()).detail; } catch { /* non-JSON error body */ }
    throw new ApiError(res.status, errorText(detail));
  }
  return res;
}

const json = (body: unknown): RequestInit => ({
  method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify(body),
```

```ts
import type { Body, Link, Vec3 } from "../api/types";

export type Box = { min: Vec3; max: Vec3 };

const cache = new WeakMap<Body, Box | null>();

export function bodyBox(b: Body): Box | null {
  if (cache.has(b)) return cache.get(b)!;
  let box: Box | null = null;
  if (b.vertices.length) {
    const min: Vec3 = [Infinity, Infinity, Infinity];
    const max: Vec3 = [-Infinity, -Infinity, -Infinity];
    for (const v of b.vertices) {
      for (let i = 0; i < 3; i++) {
        if (v[i] < min[i]) min[i] = v[i];
        if (v[i] > max[i]) max[i] = v[i];
      }
    }
    box = { min, max };
  }
  cache.set(b, box);
  return box;
}

export function unionBox(boxes: (Box | null)[]): Box | null {
  const real = boxes.filter((b): b is Box => b !== null);
  if (!real.length) return null;
  return {
    min: [0, 1, 2].map((i) => Math.min(...real.map((b) => b.min[i]))) as Vec3,
    max: [0, 1, 2].map((i) => Math.max(...real.map((b) => b.max[i]))) as Vec3,
  };
}

export const boxesOverlap = (a: Box, b: Box, tol: number) =>
  [0, 1, 2].every((i) => a.min[i] <= b.max[i] + tol && b.min[i] <= a.max[i] + tol);

export const boxVolume = (b: Box) =>
  (b.max[0] - b.min[0]) * (b.max[1] - b.min[1]) * (b.max[2] - b.min[2]);

export const linkBox = (link: Link, bodies: Record<string, Body>) =>
  unionBox(link.body_ids.map((id) => (bodies[id] ? bodyBox(bodies[id]) : null)));
```

```ts
import type { Body, Joint, Link, PartWarning } from "../api/types";
import { boxVolume, linkBox } from "./geometry";
import { DEFAULT_DENSITY, emptyModel, type ModelState, type Suggestion } from "./types";

export type LinkProps = Partial<Pick<Link, "density_kg_m3" | "mass_override_kg" | "accept_approximate_mass">>;

export type Action =
  | { type: "import"; bodies: Body[]; warnings: PartWarning[] }
  | { type: "merge"; linkIds: string[] }
  | { type: "mergeSmall"; pairs: { linkId: string; neighbourId: string }[] }
  | { type: "moveBody"; bodyId: string; toLinkId: string }
  | { type: "ignoreBody"; bodyId: string }
  | { type: "unignoreBody"; bodyId: string }
  | { type: "renameLink"; linkId: string; name: string }
  | { type: "setRoot"; linkId: string }
  | { type: "setLinkProps"; linkId: string; props: LinkProps }
  | { type: "replaceBody"; body: Body }
  | { type: "setSuggestion"; suggestion: Suggestion }
  | { type: "acceptSuggestion"; key: string; joint: Joint }
  | { type: "rejectSuggestion"; key: string }
  | { type: "addJoint"; joint: Joint }
  | { type: "updateJoint"; joint: Joint }
  | { type: "removeJoint"; jointId: string }
  | { type: "load"; model: ModelState };

export function sanitizeName(raw: string): string {
  let n = raw.trim().replace(/[^A-Za-z0-9_-]/g, "_");
  if (!n) return "part";
  if (!/^[A-Za-z0-9_]/.test(n)) n = "p" + n;
  return n;
}

function uniqueName(base: string, taken: Set<string>): string {
  let name = base;
  for (let k = 2; taken.has(name); k++) name = `${base}_${k}`;
  taken.add(name);
  return name;
}

const newId = () => crypto.randomUUID();

function newLink(body: Body, taken: Set<string>): Link {
  return {
    id: newId(), name: uniqueName(sanitizeName(body.name), taken), body_ids: [body.id],
    density_kg_m3: DEFAULT_DENSITY, mass_override_kg: null, accept_approximate_mass: false,
  };
}

/** Drop empty links, joints/suggestions on missing links, and fix the base link. */
function tidy(s: ModelState): ModelState {
  const links = s.links.filter((l) => l.body_ids.length > 0);
  const ids = new Set(links.map((l) => l.id));
  const joints = s.joints.filter(
    (j) => ids.has(j.parent_link_id) && ids.has(j.child_link_id) && j.parent_link_id !== j.child_link_id);
  const suggestions = Object.fromEntries(
    Object.entries(s.suggestions).filter(([, g]) => ids.has(g.linkA) && ids.has(g.linkB)));
  let rootLinkId = s.rootLinkId && ids.has(s.rootLinkId) ? s.rootLinkId : null;
  if (!rootLinkId && links.length) {
    const vol = (l: Link) => { const b = linkBox(l, s.bodies); return b ? boxVolume(b) : 0; };
    rootLinkId = links.reduce((best, l) => (vol(l) > vol(best) ? l : best)).id;
  }
  return { ...s, links, joints, suggestions, rootLinkId };
}

function removeBodyFromLinks(links: Link[], bodyId: string): Link[] {
  return links.map((l) => (l.body_ids.includes(bodyId)
    ? { ...l, body_ids: l.body_ids.filter((b) => b !== bodyId) } : l));
}

function mergeLinks(s: ModelState, target: string, others: string[]): ModelState {
  const moved = s.links.filter((l) => others.includes(l.id)).flatMap((l) => l.body_ids);
  const links = s.links
    .filter((l) => !others.includes(l.id))
    .map((l) => (l.id === target ? { ...l, body_ids: [...l.body_ids, ...moved] } : l));
  const remap = (id: string) => (others.includes(id) ? target : id);
  const joints = s.joints.map((j) => ({
    ...j, parent_link_id: remap(j.parent_link_id), child_link_id: remap(j.child_link_id) }));
  return { ...s, links, joints };
}

export function modelReducer(s: ModelState, a: Action): ModelState {
  switch (a.type) {
    case "import": {
      const taken = new Set(s.links.map((l) => l.name));
      const bodies = { ...s.bodies };
      for (const b of a.bodies) bodies[b.id] = b;
      const links = [...s.links, ...a.bodies.map((b) => newLink(b, taken))];
      return tidy({ ...s, bodies, links, fileWarnings: [...s.fileWarnings, ...a.warnings] });
    }
    case "merge": {
      const [target, ...others] = a.linkIds;
      if (!target || !others.length || !s.links.some((l) => l.id === target)) return s;
      return tidy(mergeLinks(s, target, others));
    }
    case "mergeSmall": {
      let next = s;
      for (const p of a.pairs) next = mergeLinks(next, p.neighbourId, [p.linkId]);
      return a.pairs.length ? tidy(next) : s;
    }
    case "moveBody": {
      if (!s.links.some((l) => l.id === a.toLinkId)) return s;
      const links = removeBodyFromLinks(s.links, a.bodyId).map((l) =>
        (l.id === a.toLinkId ? { ...l, body_ids: [...l.body_ids, a.bodyId] } : l));
      return tidy({ ...s, links });
    }
    case "ignoreBody": {
      if (!s.bodies[a.bodyId] || s.ignored.includes(a.bodyId)) return s;
      return tidy({ ...s, links: removeBodyFromLinks(s.links, a.bodyId), ignored: [...s.ignored, a.bodyId] });
    }
    case "unignoreBody": {
      if (!s.ignored.includes(a.bodyId)) return s;
      const taken = new Set(s.links.map((l) => l.name));
      return tidy({ ...s, ignored: s.ignored.filter((b) => b !== a.bodyId),
        links: [...s.links, newLink(s.bodies[a.bodyId], taken)] });
    }
    case "renameLink":
      if (!s.links.some((l) => l.id === a.linkId)) return s;
      return { ...s, links: s.links.map((l) => (l.id === a.linkId ? { ...l, name: a.name } : l)) };
    case "setRoot":
      return s.links.some((l) => l.id === a.linkId) ? { ...s, rootLinkId: a.linkId } : s;
    case "setLinkProps":
      if (!s.links.some((l) => l.id === a.linkId)) return s;
      return { ...s, links: s.links.map((l) => (l.id === a.linkId ? { ...l, ...a.props } : l)) };
    case "replaceBody":
      return s.bodies[a.body.id] ? { ...s, bodies: { ...s.bodies, [a.body.id]: a.body } } : s;
    case "setSuggestion":
      return { ...s, suggestions: { ...s.suggestions, [a.suggestion.key]: a.suggestion } };
    case "acceptSuggestion": {
      const g = s.suggestions[a.key];
      if (!g) return s;
      return { ...s, joints: [...s.joints.filter((j) => j.id !== a.joint.id), { ...a.joint, source: "confirmed" }],
        suggestions: { ...s.suggestions, [a.key]: { ...g, status: "accepted" } } };
    }
    case "rejectSuggestion": {
      const g = s.suggestions[a.key];
      return g ? { ...s, suggestions: { ...s.suggestions, [a.key]: { ...g, status: "rejected" } } } : s;
    }
    case "addJoint":
      return tidy({ ...s, joints: [...s.joints, a.joint] });
    case "updateJoint":
      return { ...s, joints: s.joints.map((j) => (j.id === a.joint.id ? a.joint : j)) };
    case "removeJoint": {
      const suggestions = Object.fromEntries(Object.entries(s.suggestions).map(([k, g]) =>
        [k, g.result.joint?.id === a.jointId && g.status === "accepted" ? { ...g, status: "review" as const } : g]));
      return { ...s, joints: s.joints.filter((j) => j.id !== a.jointId), suggestions };
    }
    case "load":
      return { ...emptyModel(), ...a.model };
  }
}
```

```ts
import type { Body, Link } from "../api/types";
import { bodyBox, boxesOverlap, type Box } from "./geometry";

export const CONTACT_TOL = 1e-4;

export const pairKey = (a: string, b: string) => [a, b].sort().join("|");

export function membership(a: Link, b: Link): string {
  const [x, y] = a.id < b.id ? [a, b] : [b, a];
  return `${[...x.body_ids].sort().join(",")}|${[...y.body_ids].sort().join(",")}`;
}

const boxes = (l: Link, bodies: Record<string, Body>): Box[] =>
  l.body_ids.map((id) => (bodies[id] ? bodyBox(bodies[id]) : null)).filter((b): b is Box => b !== null);

export function touchingPairs(links: Link[], bodies: Record<string, Body>, tol = CONTACT_TOL): [Link, Link][] {
  const out: [Link, Link][] = [];
  const bx = links.map((l) => boxes(l, bodies));
  for (let i = 0; i < links.length; i++) {
    for (let j = i + 1; j < links.length; j++) {
      if (bx[i].some((a) => bx[j].some((b) => boxesOverlap(a, b, tol)))) out.push([links[i], links[j]]);
    }
  }
  return out;
}
```

```ts
export function smallLinks(links: Link[], bodies: Record<string, Body>): { linkId: string; neighbourId: string }[] {
  const vol = new Map(links.map((l) => { const b = linkBox(l, bodies); return [l.id, b ? boxVolume(b) : 0]; }));
  const largest = Math.max(0, ...vol.values());
  if (largest <= 0) return [];
  const neighbours = new Map<string, string[]>(links.map((l) => [l.id, []]));

    neighbours.get(a.id)!.push(b.id);
    neighbours.get(b.id)!.push(a.id);
  }
  return links
    .filter((l) => vol.get(l.id)! < SMALL_FRACTION * largest && neighbours.get(l.id)!.length === 1)
    .map((l) => ({ linkId: l.id, neighbourId: neighbours.get(l.id)![0] }));
```

```ts
import type { Joint, Link } from "../api/types";

export interface TreeError { linkIds: string[]; jointId?: string; message: string }

export function directJoints(links: Link[], joints: Joint[], rootId: string | null):
  { joints: Joint[]; errors: TreeError[] } {
  const errors: TreeError[] = [];
  if (!rootId || !links.some((l) => l.id === rootId)) {
    return { joints: [], errors: [{ linkIds: [], message: "No base link chosen." }] };
  }
  const seenPairs = new Set<string>();
  const usable: Joint[] = [];
  for (const j of joints) {
    const key = [j.parent_link_id, j.child_link_id].sort().join("|");
    if (seenPairs.has(key)) {
      errors.push({ linkIds: [j.parent_link_id, j.child_link_id], jointId: j.id,
        message: "These links have more than one joint between them." });
    } else {
      seenPairs.add(key);
      usable.push(j);
    }
  }
  const visited = new Set([rootId]);
  const directed: Joint[] = [];
  const used = new Set<string>();
  const queue = [rootId];
  while (queue.length) {
    const cur = queue.shift()!;
    for (const j of usable) {
      if (used.has(j.id)) continue;
      const other = j.parent_link_id === cur ? j.child_link_id : j.child_link_id === cur ? j.parent_link_id : null;
      if (other === null) continue;
      used.add(j.id);
      if (visited.has(other)) {
        errors.push({ linkIds: [cur, other], jointId: j.id,
          message: "This joint closes a loop; a URDF must be a tree." });
        continue;
      }
      visited.add(other);
      directed.push({ ...j, parent_link_id: cur, child_link_id: other });
      queue.push(other);
    }
  }
  const unreached = links.filter((l) => !visited.has(l.id)).map((l) => l.id);
  if (unreached.length) {
    errors.push({ linkIds: unreached, message: "Not connected to the base link by any joint." });
  }
  return { joints: directed, errors };
}
```

```ts
export function splitExportError(message: string) {
  const body = message.replace(/^Cannot export URDF --\s*/, "").replace(/^structural validation failed:\s*/, "");
  const pieces = body.split(/; (?=[A-Z])/).map((p) => p.trim()).filter(Boolean);
  const byLink: Record<string, string[]> = {};
  const byJoint: Record<string, string[]> = {};
  const general: string[] = [];
  for (const p of pieces) {
    const link = /[Ll]ink '([^']+)'/.exec(p);
    const joint = /^Joint (\S+)/.exec(p);
    if (joint) (byJoint[joint[1]] ??= []).push(p);
    else if (link) (byLink[link[1]] ??= []).push(p);
    else general.push(p);
  }
  return { byLink, byJoint, general };
}
```

```ts
import { modelReducer, type Action } from "./reducer";
import { emptyModel, type ModelState } from "./types";

export const HISTORY_CAP = 100;
const NOT_UNDOABLE = new Set<Action["type"]>(["setSuggestion"]);

export interface History { past: ModelState[]; present: ModelState; future: ModelState[] }
export type HistoryAction = Action | { type: "undo" } | { type: "redo" };

export const initialHistory = (): History => ({ past: [], present: emptyModel(), future: [] });

export function historyReducer(h: History, a: HistoryAction): History {
  if (a.type === "undo") {
    if (!h.past.length) return h;
    return { past: h.past.slice(0, -1), present: h.past[h.past.length - 1], future: [h.present, ...h.future] };
  }
  if (a.type === "redo") {
    if (!h.future.length) return h;
    return { past: [...h.past, h.present], present: h.future[0], future: h.future.slice(1) };
  }
  const next = modelReducer(h.present, a);
  if (next === h.present) return h;
  if (a.type === "load") return { past: [], present: next, future: [] };
  if (NOT_UNDOABLE.has(a.type)) return { ...h, present: next };
  return { past: [...h.past, h.present].slice(-HISTORY_CAP), present: next, future: [] };
}
```

```ts
import type { Body, DetectResponse } from "../api/types";
import { membership, pairKey, touchingPairs } from "./pairs";
import type { ModelState } from "./types";

export interface PendingPair { key: string; linkA: string; linkB: string; membership: string }
export type DetectFn = (a: Body[], b: Body[], linkA: string, linkB: string, signal: AbortSignal) => Promise<DetectResponse>;
export interface Progress { done: number; total: number; running: boolean; paused: boolean }

export function pairsToDetect(m: ModelState): PendingPair[] {
  return touchingPairs(m.links, m.bodies)
    .map(([a, b]) => ({ key: pairKey(a.id, b.id), linkA: a.id, linkB: b.id, membership: membership(a, b) }))
    .filter((p) => m.suggestions[p.key]?.membership !== p.membership);
}

interface Handlers {
  onResult(p: PendingPair, r: DetectResponse): void;
  onProgress(p: Progress): void;
  onError(message: string): void;
}

const same = (a: PendingPair, b: PendingPair) => a.key === b.key && a.membership === b.membership;

export class DetectionRunner {
  private pending: PendingPair[] = [];
  private current: { pair: PendingPair; ctrl: AbortController } | null = null;
  private bodiesOf: (linkId: string) => Body[] = () => [];
  private paused = false;
  private done = 0;

  constructor(private detect: DetectFn, private handlers: Handlers) {}

  update(pairs: PendingPair[], bodiesOf: (linkId: string) => Body[]) {
    this.bodiesOf = bodiesOf;
    this.pending = pairs.filter((p) => !(this.current && same(p, this.current.pair)));
    if (this.current && !pairs.some((p) => same(p, this.current!.pair))) {
      this.current.ctrl.abort();
      this.current = null;
    }
    if (!this.pending.length && !this.current) this.done = 0;
    this.report();
    void this.kick();
  }

  cancel() {
    this.paused = true;
    if (this.current) {
      this.pending.unshift(this.current.pair);
      this.current.ctrl.abort();
      this.current = null;
    }
    this.report();
  }

  resume() {
    this.paused = false;
    this.report();
    void this.kick();
  }

  private report() {
    const running = this.current !== null;
    this.handlers.onProgress({
      done: this.done, total: this.done + this.pending.length + (running ? 1 : 0), running, paused: this.paused });
  }

  private async kick() {
    if (this.paused || this.current || !this.pending.length) return;
    const pair = this.pending.shift()!;
    const ctrl = new AbortController();
    this.current = { pair, ctrl };
    this.report();
    try {
      const result = await this.detect(this.bodiesOf(pair.linkA), this.bodiesOf(pair.linkB), pair.linkA, pair.linkB, ctrl.signal);
      if (this.current?.ctrl !== ctrl) return;   // superseded while running
      this.current = null;
      this.done++;
      this.handlers.onResult(pair, result);
    } catch (e) {
      if (ctrl.signal.aborted) return;
      if (this.current?.ctrl === ctrl) this.current = null;
      this.pending.unshift(pair);
      this.paused = true;
      this.handlers.onError((e as Error).message);
    }
    this.report();
    void this.kick();
  }
}
```

```ts
export function bodyArrays(b: Body) {
  const positions = new Float32Array(b.vertices.length * 3);
  b.vertices.forEach((v, i) => positions.set(v, i * 3));
  const indices = new Uint32Array(b.triangles.length * 3);
```

```ts
import { Matrix4, Vector3 } from "three";
import type { Joint } from "../api/types";

export function jointMotion(j: Joint, value: number): Matrix4 {
  if (!j.axis) return new Matrix4();
  const axis = new Vector3(...j.axis).normalize();
  const o = new Vector3(...j.origin_xyz);
  if (j.type === "revolute" || j.type === "continuous") {
    return new Matrix4().makeTranslation(o.x, o.y, o.z)
      .multiply(new Matrix4().makeRotationAxis(axis, value))
      .multiply(new Matrix4().makeTranslation(-o.x, -o.y, -o.z));
  }
  if (j.type === "prismatic") {
    const d = axis.multiplyScalar(value);
    return new Matrix4().makeTranslation(d.x, d.y, d.z);
  }
  return new Matrix4();
}

export function previewRange(j: Joint): [number, number] {
  if (j.type === "continuous") return [-Math.PI, Math.PI];
  if ((j.type === "revolute" || j.type === "prismatic") && j.limit_lower !== null && j.limit_upper !== null) {
    return [j.limit_lower, j.limit_upper];
  }
  return [0, 0];
}

export function subtreeLinks(directed: Joint[], jointId: string): string[] {
  const start = directed.find((j) => j.id === jointId);
  if (!start) return [];
  const out = [start.child_link_id];
  for (let i = 0; i < out.length; i++) {
    for (const j of directed) if (j.parent_link_id === out[i]) out.push(j.child_link_id);
  }
  return out;
}
```

```ts
import {
  AmbientLight, ArrowHelper, Box3, BufferAttribute, BufferGeometry, Color, DirectionalLight, Group, Matrix4,
  Mesh, MeshStandardMaterial, Object3D, PerspectiveCamera, Raycaster, Scene, Vector2, Vector3, WebGLRenderer,
} from "three";
import { OrbitControls } from "three/examples/jsm/controls/OrbitControls.js";
import { TransformControls } from "three/examples/jsm/controls/TransformControls.js";
import type { Body, Joint, Vec3 } from "../api/types";
import { bodyArrays, statusColor } from "./meshData";

type PickCb = (hit: { bodyId: string; triangle: number } | null, additive: boolean) => void;

export class Viewer {
  private renderer: WebGLRenderer;
  private scene = new Scene();
  private camera = new PerspectiveCamera(45, 1, 0.001, 1000);
  private controls: OrbitControls;
  private meshes = new Map<string, Mesh>();
  private joints = new Group();
  private gizmo: TransformControls;
  private gizmoTarget = new Object3D();
  private pickCb: PickCb = () => {};
  private frame = 0;
  private framed = false;

  constructor(private container: HTMLElement) {
    this.renderer = new WebGLRenderer({ antialias: true });
    this.renderer.setPixelRatio(window.devicePixelRatio);
    container.appendChild(this.renderer.domElement);
    this.scene.background = new Color(0xf4f6f8);
    this.scene.add(new AmbientLight(0xffffff, 0.6));
    const sun = new DirectionalLight(0xffffff, 0.9);
    sun.position.set(3, 5, 4);
    this.scene.add(sun, this.joints, this.gizmoTarget);
    this.camera.up.set(0, 0, 1);
    this.camera.position.set(2, -2, 1.5);
    this.controls = new OrbitControls(this.camera, this.renderer.domElement);
    this.gizmo = new TransformControls(this.camera, this.renderer.domElement);
    this.gizmo.addEventListener("dragging-changed", (e) => { this.controls.enabled = !e.value; });
    this.renderer.domElement.addEventListener("pointerdown", this.onPointer);
    new ResizeObserver(() => this.resize()).observe(container);
    this.resize();
    const loop = () => { this.renderer.render(this.scene, this.camera); this.frame = requestAnimationFrame(loop); };
    loop();
  }

  private resize() {
    const { clientWidth: w, clientHeight: h } = this.container;
    this.renderer.setSize(w, h);
    this.camera.aspect = w / Math.max(h, 1);
    this.camera.updateProjectionMatrix();
  }

  setBodies(bodies: Body[], ignored: Set<string>) {
    const keep = new Set(bodies.map((b) => b.id));
    for (const [id, m] of this.meshes) {
      if (!keep.has(id)) { this.scene.remove(m); m.geometry.dispose(); this.meshes.delete(id); }
    }
    for (const b of bodies) {
      let mesh = this.meshes.get(b.id);
      if (!mesh || mesh.userData.source !== b) {
        if (mesh) { this.scene.remove(mesh); mesh.geometry.dispose(); }
        const { positions, indices } = bodyArrays(b);
        const g = new BufferGeometry();
        g.setAttribute("position", new BufferAttribute(positions, 3));
        g.setIndex(new BufferAttribute(indices, 1));
        g.computeVertexNormals();
        mesh = new Mesh(g, new MeshStandardMaterial({ color: statusColor(b.status) }));
        mesh.userData = { bodyId: b.id, source: b };
        this.scene.add(mesh);
        this.meshes.set(b.id, mesh);
      }
      const mat = mesh.material as MeshStandardMaterial;
      mat.color.setHex(statusColor(b.status));
      mat.transparent = ignored.has(b.id);
      mat.opacity = ignored.has(b.id) ? 0.2 : 1;
    }
    if (!this.framed && bodies.length) this.frameAll();
  }

  private frameAll() {
    const size = new Vector3(), center = new Vector3();
    const b = new Box3();
    for (const m of this.meshes.values()) b.expandByObject(m);
    b.getSize(size); b.getCenter(center);
    const box = size;
    const d = Math.max(box.x, box.y, box.z) * 1.8 || 1;
    this.camera.position.copy(center).add(new Vector3(d, -d, d * 0.7));
    this.controls.target.copy(center);
    this.controls.update();
    this.framed = true;
  }

  setSelection(bodyIds: string[]) {
    for (const [id, m] of this.meshes) {
      (m.material as MeshStandardMaterial).emissive.setHex(bodyIds.includes(id) ? 0x2266cc : 0x000000);
    }
  }

  setJoints(items: { joint: Joint; dashed: boolean }[]) {
    this.joints.clear();
    for (const { joint, dashed } of items) {
      if (!joint.axis) continue;
      const arrow = new ArrowHelper(new Vector3(...joint.axis).normalize(), new Vector3(...joint.origin_xyz),
        0.1, dashed ? 0x999999 : 0x1565c0);
      this.joints.add(arrow);
    }
  }

  setPreview(bodyIds: string[], m: Matrix4 | null) {
    for (const [id, mesh] of this.meshes) {
      mesh.matrixAutoUpdate = false;
      mesh.matrix.copy(m && bodyIds.includes(id) ? m : new Matrix4());
      mesh.matrixWorldNeedsUpdate = true;
    }
  }

  onPick(cb: PickCb) { this.pickCb = cb; }

  private onPointer = (e: PointerEvent) => {
    if (this.gizmo.dragging) return;
    const r = this.renderer.domElement.getBoundingClientRect();
    const ndc = new Vector2(((e.clientX - r.left) / r.width) * 2 - 1, -((e.clientY - r.top) / r.height) * 2 + 1);
    const ray = new Raycaster();
    ray.setFromCamera(ndc, this.camera);
    const hit = ray.intersectObjects([...this.meshes.values()], false)[0];
    this.pickCb(hit ? { bodyId: hit.object.userData.bodyId, triangle: hit.faceIndex ?? -1 } : null, e.shiftKey);
  };

  attachGizmo(origin: Vec3, axis: Vec3, onChange: (origin: Vec3, axis: Vec3) => void) {
    this.gizmoTarget.position.set(...origin);
    this.gizmoTarget.quaternion.setFromUnitVectors(new Vector3(0, 0, 1), new Vector3(...axis).normalize());
    this.gizmo.attach(this.gizmoTarget);
    this.scene.add(this.gizmo.getHelper ? this.gizmo.getHelper() : (this.gizmo as unknown as Object3D));
    this.gizmo.removeEventListener("objectChange", this.gizmoChange);
    this.gizmoChange = () => {
      const p = this.gizmoTarget.position;
      const a = new Vector3(0, 0, 1).applyQuaternion(this.gizmoTarget.quaternion);
      onChange([p.x, p.y, p.z], [a.x, a.y, a.z]);
    };
    this.gizmo.addEventListener("objectChange", this.gizmoChange);
  }
  private gizmoChange = () => {};

  setGizmoMode(mode: "translate" | "rotate") { this.gizmo.setMode(mode); }

  detachGizmo() {
    this.gizmo.detach();
    this.scene.remove(this.gizmo.getHelper ? this.gizmo.getHelper() : (this.gizmo as unknown as Object3D));
  }

  dispose() {
    cancelAnimationFrame(this.frame);
    this.renderer.domElement.removeEventListener("pointerdown", this.onPointer);
    this.controls.dispose();
    this.gizmo.dispose();
    for (const m of this.meshes.values()) m.geometry.dispose();
    this.renderer.dispose();
    this.renderer.domElement.remove();
  }
}
```

```tsx
        onProgress: setProgress,

      });

    runner.current!.update(pairsToDetect(model), (linkId) =>
      (model.links.find((l) => l.id === linkId)?.body_ids ?? []).map((id) => model.bodies[id]));

    ...model.joints.map((joint) => ({ joint, dashed: false })),
```

```tsx
import type { Joint } from "../api/types";
import type { DetailsProps } from "./DetailsPanel";

const REASON = { no_overlap: "parts don't overlap", no_contact_faces: "no contact faces found" } as const;

export default function Overview({ model, dispatch, selection, setSelection }: DetailsProps) {
  const sugs = Object.values(model.suggestions);
  const name = (id: string) => model.links.find((l) => l.id === id)?.name ?? id;
  const pairLabel = (a: string, b: string) => `${name(a)} ↔ ${name(b)}`;
  const selectedLinks = selection?.kind === "bodies"
    ? [...new Set(selection.ids.map((b) => model.links.find((l) => l.body_ids.includes(b))?.id).filter(Boolean))] as string[]
    : [];

  const addManual = () => {
    const [a, b] = selectedLinks;
    const box = (id: string) => {
      const vs = model.links.find((l) => l.id === id)!.body_ids.flatMap((bid) => model.bodies[bid].vertices);
      const lo = [0, 1, 2].map((i) => Math.min(...vs.map((v) => v[i])));
      const hi = [0, 1, 2].map((i) => Math.max(...vs.map((v) => v[i])));
      return { lo, hi };
    };
    const A = box(a), B = box(b);
    const lo = [0, 1, 2].map((i) => Math.max(A.lo[i], B.lo[i]));
    const hi = [0, 1, 2].map((i) => Math.min(A.hi[i], B.hi[i]));
    const overlaps = [0, 1, 2].every((i) => lo[i] <= hi[i]);
    const origin = [0, 1, 2].map((i) => overlaps ? (lo[i] + hi[i]) / 2
      : ((A.lo[i] + A.hi[i]) / 2 + (B.lo[i] + B.hi[i]) / 2) / 2) as [number, number, number];
    const joint: Joint = { id: crypto.randomUUID(), parent_link_id: a, child_link_id: b, type: "fixed",
      origin_xyz: origin, origin_rpy: [0, 0, 0], axis: [0, 0, 1], limit_lower: null, limit_upper: null, source: "manual" };
    dispatch({ type: "addJoint", joint });
    setSelection({ kind: "joint", id: joint.id });
  };

  const section = (title: string, status: "review" | "accepted" | "rejected") => (
    <>
      <h4>{title}</h4>
      {sugs.filter((g) => g.status === status && g.result.joint).map((g) => (
        <div key={g.key} data-testid={`suggestion-${g.key}`} style={{ cursor: "pointer" }}
          onClick={() => setSelection({ kind: "suggestion", key: g.key })}>
          {pairLabel(g.linkA, g.linkB)}: {g.result.joint!.type}{g.result.joint!.ambiguous ? " ⚠" : ""}

      ))}
    </>
  );

      <h4>Accepted / manual joints</h4>
      {model.joints.map((j) => (

          {pairLabel(j.parent_link_id, j.child_link_id)}: {j.type} ({j.source})
```

```tsx
import { useEffect, useState } from "react";
import type { Joint, JointType, Vec3 } from "../api/types";
import { directJoints } from "../model/tree";
import { faceAtTriangle } from "../viewer/meshData";
import { jointMotion, previewRange, subtreeLinks } from "../viewer/preview";
import type { DetailsProps } from "./DetailsPanel";

const URDF_TYPES: JointType[] = ["revolute", "continuous", "prismatic", "fixed", "planar"];
const NEEDS_LIMITS = new Set<JointType>(["revolute", "prismatic"]);

export default function JointDetails(p: DetailsProps) {
  const { model, dispatch, selection, viewer, setPreview, lastPick, setSelection } = p;
  const suggestion = selection?.kind === "suggestion" ? model.suggestions[selection.key] : null;
  const stored = selection?.kind === "joint" ? model.joints.find((j) => j.id === selection.id) ?? null : null;
  const source = stored ?? suggestion?.result.joint ?? null;
  const [draft, setDraft] = useState<Joint | null>(source);
  const [editing, setEditing] = useState(false);
  const [preview, setPreviewValue] = useState(0);
  useEffect(() => { setDraft(source); setEditing(false); }, [source?.id]);   // eslint-disable-line react-hooks/exhaustive-deps
  useEffect(() => {
    if (!editing || !viewer || !draft?.axis) { viewer?.detachGizmo(); return; }
    viewer.attachGizmo(draft.origin_xyz, draft.axis, (origin, axis) =>
      setDraft((d) => (d ? { ...d, origin_xyz: origin, axis } : d)));
    return () => viewer.detachGizmo();
  }, [editing, viewer, draft?.id]);   // eslint-disable-line react-hooks/exhaustive-deps
  if (!draft) return <div>Nothing to show.</div>;

  const typeOk = URDF_TYPES.includes(draft.type);
  const limitsOk = !NEEDS_LIMITS.has(draft.type) || (draft.limit_lower !== null && draft.limit_upper !== null
    && draft.limit_lower <= draft.limit_upper);
  const canSave = typeOk && limitsOk;
  const num = (v: string) => (v === "" ? null : Number(v));

  const snap = (mode: "cylinder" | "normal") => {
    if (!lastPick) return;
    const face = faceAtTriangle(model.bodies[lastPick.bodyId], lastPick.triangle);
    const axis: Vec3 | null = mode === "cylinder" ? face?.axis ?? null : face?.normal ?? null;
    if (axis) setDraft({ ...draft, axis, origin_xyz: mode === "cylinder" && face ? face.center : draft.origin_xyz });
  };

  const onPreview = (value: number) => {
    setPreviewValue(value);
    const { joints } = directJoints(model.links, [...model.joints.filter((j) => j.id !== draft.id), draft], model.rootLinkId);
    const links = subtreeLinks(joints, draft.id);
    const bodyIds = model.links.filter((l) => links.includes(l.id)).flatMap((l) => l.body_ids);
    setPreview({ bodyIds, matrix: jointMotion(draft, value) });
  };
  const [lo, hi] = previewRange(draft);

  return (
    <div>
      <h3>{suggestion ? "Suggested joint" : `Joint (${draft.source})`}</h3>
      <label>Type{" "}
        <select data-testid="joint-type" value={typeOk ? draft.type : ""}
          onChange={(e) => setDraft({ ...draft, type: e.target.value as JointType })}>
          {!typeOk && <option value="">{draft.type} — choose a URDF type</option>}
          {URDF_TYPES.map((t) => <option key={t} value={t}>{t}</option>)}
        </select>
      </label>
      {NEEDS_LIMITS.has(draft.type) && (
        <div>
          <label>Lower <input data-testid="limit-lower" type="number" step="any" value={draft.limit_lower ?? ""}
            onChange={(e) => setDraft({ ...draft, limit_lower: num(e.target.value) })} /></label>
          <label>Upper <input data-testid="limit-upper" type="number" step="any" value={draft.limit_upper ?? ""}
            onChange={(e) => setDraft({ ...draft, limit_upper: num(e.target.value) })} /></label>
        </div>
      )}
      <div>Origin: {draft.origin_xyz.map((x) => x.toFixed(4)).join(", ")}</div>
      <div>Axis: {draft.axis ? draft.axis.map((x) => x.toFixed(3)).join(", ") : "none"}</div>
      {suggestion?.result.evidence && (
        <ul data-testid="evidence">
          {suggestion.result.evidence.pairs.map((e, i) => (
            <li key={i}>{e.kind}{e.radius !== null ? ` r=${(e.radius * 1000).toFixed(1)} mm` : ""}</li>
          ))}
          <li>{suggestion.result.evidence.candidate_count} candidate pair(s), tolerance {suggestion.result.evidence.tolerance} m</li>
        </ul>
      )}
      {draft.ambiguous && <div className="status-approximate">⚠ ambiguous: several matching features</div>}

      <button data-testid="edit" onClick={() => setEditing((x) => !x)}>{editing ? "Done editing" : "Edit"}</button>
      {editing && (
        <>
          <button onClick={() => viewer?.setGizmoMode("translate")}>Move</button>
          <button onClick={() => viewer?.setGizmoMode("rotate")}>Rotate axis</button>
          <button data-testid="snap-cylinder" disabled={!lastPick} onClick={() => snap("cylinder")}>Axis along picked cylinder</button>
          <button data-testid="snap-normal" disabled={!lastPick} onClick={() => snap("normal")}>Axis along picked face normal</button>
        </>
      )}

      {lo !== hi && (
        <label>Preview{" "}
          <input data-testid="preview-slider" type="range" min={lo} max={hi} step={(hi - lo) / 100}
            value={preview} data-preview-value={preview}
            onChange={(e) => onPreview(Number(e.target.value))}
            onMouseUp={() => { setPreviewValue(0); setPreview(null); }} />
        </label>
      )}

      <div style={{ marginTop: 8, display: "flex", gap: 4 }}>
        {suggestion && suggestion.status !== "accepted" && (
          <button data-testid="accept" disabled={!canSave}
            onClick={() => dispatch({ type: "acceptSuggestion", key: suggestion.key, joint: draft })}>Accept</button>
        )}
        {suggestion && suggestion.status === "review" && (
          <button data-testid="reject" onClick={() => dispatch({ type: "rejectSuggestion", key: suggestion.key })}>Reject</button>
        )}
        {stored && (
          <>
            <button data-testid="save-joint" disabled={!canSave}
              onClick={() => dispatch({ type: "updateJoint", joint: draft })}>Save</button>
            <button data-testid="remove-joint" onClick={() => { dispatch({ type: "removeJoint", jointId: draft.id }); setSelection(null); }}>
              Remove
            </button>
          </>
        )}
      </div>
    </div>
  );
}
```

```ts
import type { Body, Joint, Link } from "../api/types";
import { directJoints, type TreeError } from "./tree";
import type { ModelState } from "./types";

export function buildExportRequest(m: ModelState):
  { links: Link[]; joints: Joint[]; bodiesByLink: Record<string, Body[]>; errors: TreeError[] } {
  const { joints, errors } = directJoints(m.links, m.joints, m.rootLinkId);
  const bodiesByLink = Object.fromEntries(m.links.map((l) => [l.id, l.body_ids.map((id) => m.bodies[id])]));
  return { links: m.links, joints, bodiesByLink, errors };
}
```
