# Guided UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the frontend's UI layer with a guided, graphical, Fusion-style workflow (Parts → Group → Connect → Export) that a first-time user can follow from import to URDF zip.

**Architecture:** The model layer (`src/model/*`: reducer, history, detection, tree, export request), the API client and the backend stay. New pure model helpers (base guess, next joint, problems, export checklist, joint drafts) carry the logic and are unit-tested. The three.js `Viewer` gains render-on-demand, neutral materials, overlays (joint glyphs, snap glyph, limit handles, loose-link lines, approximate wireframe) and view controls. The React UI is rewritten around one `Ctx` object passed to a stepper, a browser panel, four step panels, a floating Joint tool and an anchored info card.

**Tech Stack:** React 18 + TypeScript (Vite), three.js 0.169, Vitest + Testing Library (jsdom), Playwright; new: `lucide-react`, `@fontsource-variable/inter`.

**Spec:** `docs/superpowers/specs/2026-10-08-guided-ui-design.md` (builds on `docs/superpowers/specs/2026-10-08-frontend-design.md`).

### Plan rulings against the spec (decided while planning)

- **R-a** Spec §5 "red wireframe box at the original bounding box" for failed parts is dropped: a failed `Body` has no vertices and no stored box, so there is nothing to draw. Failed parts show in the Parts step card and the Browser (red dot). Cost if wrong: backend importer change later.
- **R-b** Spec §6.1 "Re-import at this scale" becomes a hint: "Wrong size? Undo the import (Ctrl+Z), change the scale and import again." Import is already undoable; a re-import action would need a new reducer action.
- **R-c** Spec §5 "hatched overlay" for approximate parts is an amber wireframe overlay (meshes have no UVs for a hatch texture).
- **R-d** Spec §4 "view cube" is an HTML view control (Top/Front/Right/Left/Back/Iso/Home) in the viewport corner, not a 3D cube.
- **R-e** Choosing Revolute pre-fills limits −180°…+180°; Slider pre-fills 0…100 mm. The user drags or types them; OK is never blocked by empty limits on first choice.
- **R-f** Spec §6.4 maps export 422 pieces to checklist items (with link/joint names), not to 3D pins.
- **R-g** Joint animation and "Play all joints" drive `viewer.setPreview` directly (no React state per frame).

## Review Focus

- **Undo/redo while the Joint tool is editing that joint** — the tool must resync to the stored joint or close, never save stale values. Test: Task 9 `undo while editing closes the tool when the joint disappears`.
- **A second import into a project whose base the user chose** — the base must stay. Test: Task 2 `a second import keeps the chosen base`.
- **Opening Connect while detection is still running** — show "Checking which parts touch…", no crash, no "Not connected" button for unknown pairs. Test: Task 9 `while detection runs with no candidate, says it is checking`.
- **Clicking empty space or an ignored part while picking (base / fixed / moving / origin)** — nothing changes and the pick mode stays. Test: Task 6 `empty space keeps the pick mode`.
- **Renaming a link to an invalid or duplicate name** — not stored; the field shows why and reverts on blur. Test: Task 8 `invalid and duplicate names are not stored`.

```ts
export const GLOSSARY = {
  link: ["Link", "A set of parts bolted together that move as one piece. Each link becomes one <link> in the URDF."],
  base: ["Base link", "The link that stays still — usually the part that sits on the ground. Every other link hangs off it through joints."],
  joint: ["Joint", "Connects two links and says how one moves relative to the other."],
  origin: ["Joint origin", "The point the joint moves around, for example the centre of a shaft."],
  axis: ["Axis", "The direction the joint turns around or slides along."],
  rigid: ["Rigid (URDF: fixed)", "The two links are locked together and never move relative to each other."],
  revolute: ["Revolute (URDF: revolute)", "Turns around the axis between a lower and an upper limit, like an elbow."],
  continuous: ["No limits (URDF: continuous)", "A revolute joint that can spin forever, like a wheel."],
  slider: ["Slider (URDF: prismatic)", "Slides along the axis between two limits, like a drawer."],
  planar: ["Planar (URDF: planar)", "Slides freely in the plane perpendicular to the axis. Rare in robot arms — if the preview looks wrong, pick Revolute."],
  cylindrical: ["Cylindrical", "Turns and slides on the same axis. URDF can't express this — use two joints instead."],
  ball: ["Ball", "Turns in every direction. URDF can't express this — use three revolute joints instead."],
  limits: ["Limits", "How far the joint may turn (degrees) or slide (millimetres) from where the parts are now."],
  mass: ["Mass", "How heavy the link is. Simulators need it to move the robot realistically."],
  inertia: ["Inertia", "How the link's mass is spread out; it decides how hard the link is to spin. Computed from the shape."],
  estimated: ["Estimated mass", "Mass computed from the part's volume and its material's density."],
  approximate: ["Approximate shape", "The part's surface has gaps, so its volume — and with it the mass — is only an estimate."],
  failed: ["Failed part", "The file had no usable shape for this part. Replace it with a fixed file, or ignore it."],
  urdf: ["URDF", "Unified Robot Description Format: the XML file ROS, Gazebo and most robot simulators use to describe a robot."],
  mesh: ["Mesh", "The 3D surface of a link, saved as an STL file next to the URDF."],
  scale: ["Scale", "Multiplier from file units to metres. STL, OBJ and BREP files carry no units: 0.001 means the file is in millimetres."],
  name: ["Names", "URDF names may use letters, digits, _ and - only, and must start with a letter, digit or _."],
  suggested: ["Suggested from contact faces", "The app found faces where the two links touch (shafts in holes, flat bearing faces) and guessed the joint from them."],
} as const satisfies Record<string, readonly [string, string]>;

export type Term = keyof typeof GLOSSARY;
```

```tsx
import { Info as InfoIcon } from "lucide-react";
import { useId, useState } from "react";
import { GLOSSARY, type Term } from "./glossary";

export default function Info({ term }: { term: Term }) {
  const [open, setOpen] = useState(false);
  const id = useId();

  return (
    <span className="info" onMouseEnter={() => setOpen(true)} onMouseLeave={() => setOpen(false)}>
      <button type="button" className="info-btn" aria-label={`What is ${title}?`} aria-describedby={open ? id : undefined}

        <InfoIcon size={13} />
      </button>
      {open && <span role="tooltip" id={id} className="info-card"><strong>{title}</strong>{text}</span>}
    </span>
  );
}
```

```ts
/** Middle-ellipsis: "IRB1300_7_12KG-1400-IP40-338203" → "IRB1300_…338203". */
export function shortName(name: string, max = 24): string {
  if (name.length <= max) return name;
  const keep = max - 1;
  const head = Math.ceil(keep / 2);
  const tail = Math.floor(keep / 2);
  return `${name.slice(0, head)}…${name.slice(name.length - tail)}`;
}

export const deg = (r: number) => (r * 180) / Math.PI;
export const rad = (d: number) => (d * Math.PI) / 180;
export const fmtLen = (m: number) => (Math.abs(m) >= 1 ? `${m.toFixed(2)} m` : `${(m * 1000).toFixed(0)} mm`);
```

```ts
/** The link that most likely sits on the ground: lowest box bottom, ties broken by larger volume. */
export function baseGuess(links: Link[], bodies: Record<string, Body>): string | null {
  let best: { id: string; z: number; v: number } | null = null;
  for (const l of links) {
    const b = linkBox(l, bodies);
    if (!b) continue;
    const z = b.min[2];
    const v = boxVolume(b);
    if (!best || z < best.z - 1e-9 || (Math.abs(z - best.z) <= 1e-9 && v > best.v)) best = { id: l.id, z, v };
  }
  return best?.id ?? links[0]?.id ?? null;
}
```

```ts
import { pairKey, touchingPairs } from "./pairs";
import type { ModelState, Suggestion } from "./types";

export interface NextPair { fixed: string; moving: string; suggestion: Suggestion | null }

/** Link id → number of joints between it and the base, following joints in either direction. */
export function chainDepth(m: ModelState): Map<string, number> {
  const depth = new Map<string, number>();
  if (!m.rootLinkId) return depth;
  depth.set(m.rootLinkId, 0);
  const queue = [m.rootLinkId];
  while (queue.length) {
    const cur = queue.shift()!;
    for (const j of m.joints) {
      const other = j.parent_link_id === cur ? j.child_link_id : j.child_link_id === cur ? j.parent_link_id : null;
      if (other !== null && !depth.has(other)) {
        depth.set(other, depth.get(cur)! + 1);
        queue.push(other);
      }
    }
  }
  return depth;
}

/** The next joint to set up, walking out from the base: a touching pair with exactly one side
 *  connected, pairs with a detected joint first, then nearest the base, then detection order. */
export function nextJoint(m: ModelState, onlyLink?: string): NextPair | null {
  const depth = chainDepth(m);
  const options: (NextPair & { d: number; i: number })[] = [];
  touchingPairs(m.links, m.bodies).forEach(([a, b], i) => {
    if (onlyLink && a.id !== onlyLink && b.id !== onlyLink) return;
    const inA = depth.has(a.id);
    if (inA === depth.has(b.id)) return;
    const g = m.suggestions[pairKey(a.id, b.id)];
    if (g?.status === "rejected") return;
    const [fixed, moving] = inA ? [a.id, b.id] : [b.id, a.id];
    options.push({ fixed, moving, suggestion: g?.status === "review" && g.result.joint ? g : null, d: depth.get(fixed)!, i });
  });
  options.sort((x, y) => Number(!x.suggestion) - Number(!y.suggestion) || x.d - y.d || x.i - y.i);
  const best = options[0];
  return best ? { fixed: best.fixed, moving: best.moving, suggestion: best.suggestion } : null;
}
```

```ts
import type { PartWarning } from "../api/types";
import type { ModelState } from "./types";

export type Problem =
  | { kind: "failed"; bodyId: string }
  | { kind: "approximate"; bodyId: string; linkId: string }
  | { kind: "warning"; bodyId: string; warning: PartWarning };

/** Problems the Parts step shows, in body order. Ignored parts and resolved approximate parts drop out. */
export function partProblems(m: ModelState): Problem[] {
  const out: Problem[] = [];
  for (const b of Object.values(m.bodies)) {
    if (m.ignored.includes(b.id)) continue;
    const link = m.links.find((l) => l.body_ids.includes(b.id));
    if (b.status === "failed") {
      out.push({ kind: "failed", bodyId: b.id });
    } else if (b.status === "approximate") {
      if (link && !link.accept_approximate_mass && link.mass_override_kg === null) {
        out.push({ kind: "approximate", bodyId: b.id, linkId: link.id });
      }
    } else {
      for (const w of b.warnings) out.push({ kind: "warning", bodyId: b.id, warning: w });
    }
  }
  return out;
}
```

```ts
import type { Body, Joint, JointType, Vec3 } from "../api/types";
import { linkBox } from "./geometry";
import type { NextPair } from "./nextJoint";
import type { ModelState, Suggestion } from "./types";

export type Motion = "rigid" | "revolute" | "slider" | "planar";

export interface JointDraft {
  id: string;
  fixed: string | null;
  moving: string | null;
  origin: Vec3 | null;
  axis: Vec3 | null;
  motion: Motion | null;
  noLimits: boolean;
  lower: number | null;   // radians (revolute) or metres (slider)
  upper: number | null;
  suggestionKey: string | null;
  detected: JointType | null;
  ambiguous: boolean;
  source: Joint["source"];
}

export const DEFAULT_LIMITS: { revolute: [number, number]; slider: [number, number] } = {
  revolute: [-Math.PI, Math.PI], slider: [0, 0.1],
};

export function motionOf(t: JointType): Motion | null {
  switch (t) {
    case "fixed": return "rigid";
    case "revolute": case "continuous": case "cylindrical": return "revolute";
    case "prismatic": return "slider";
    case "planar": return "planar";
    default: return null;
  }
}

export function jointType(d: Pick<JointDraft, "motion" | "noLimits">): JointType | null {
  switch (d.motion) {
    case "rigid": return "fixed";
    case "revolute": return d.noLimits ? "continuous" : "revolute";
    case "slider": return "prismatic";
    case "planar": return "planar";
    default: return null;
  }
}

export function emptyDraft(fixed: string | null = null, moving: string | null = null): JointDraft {
  return { id: crypto.randomUUID(), fixed, moving, origin: null, axis: null, motion: null, noLimits: false,
    lower: null, upper: null, suggestionKey: null, detected: null, ambiguous: false, source: "manual" };
}

export function setMotion(d: JointDraft, motion: Motion): JointDraft {
  if (d.motion === motion) return d;
  const lim = motion === "revolute" || motion === "slider" ? DEFAULT_LIMITS[motion] : null;
  return { ...d, motion, lower: lim?.[0] ?? null, upper: lim?.[1] ?? null };
}

export function draftFromJoint(j: Joint, suggestionKey: string | null = null): JointDraft {
  const d: JointDraft = { id: j.id, fixed: j.parent_link_id, moving: j.child_link_id, origin: j.origin_xyz,
    axis: j.axis, motion: motionOf(j.type), noLimits: j.type === "continuous", lower: j.limit_lower,
    upper: j.limit_upper, suggestionKey, detected: j.source === "suggested" ? j.type : null,
    ambiguous: !!j.ambiguous, source: j.source };
  const limited = (d.motion === "revolute" && !d.noLimits) || d.motion === "slider";
  if (limited && (d.lower === null || d.upper === null)) {
    const [lo, hi] = DEFAULT_LIMITS[d.motion as "revolute" | "slider"];
    return { ...d, lower: lo, upper: hi };
  }
  return d;
}

/** The connected link (`fixed`) is the parent whichever way detection ordered the pair. */
export function draftFromSuggestion(g: Suggestion, fixed: string): JointDraft {
  const j = g.result.joint!;
  const moving = j.parent_link_id === fixed ? j.child_link_id : j.parent_link_id;
  return draftFromJoint({ ...j, parent_link_id: fixed, child_link_id: moving }, g.key);
}

export function contactCenter(m: ModelState, a: string, b: string): Vec3 | null {
  const la = m.links.find((l) => l.id === a);
  const lb = m.links.find((l) => l.id === b);
  const A = la ? linkBox(la, m.bodies) : null;
  const B = lb ? linkBox(lb, m.bodies) : null;
  if (!A || !B) return null;
  return [0, 1, 2].map((i) => {
    const lo = Math.max(A.min[i], B.min[i]);
    const hi = Math.min(A.max[i], B.max[i]);
    return lo <= hi ? (lo + hi) / 2 : (A.min[i] + A.max[i] + B.min[i] + B.max[i]) / 4;
  }) as Vec3;
}

export function draftForPair(m: ModelState, n: NextPair): JointDraft {
  if (n.suggestion) return draftFromSuggestion(n.suggestion, n.fixed);
  return { ...emptyDraft(n.fixed, n.moving), origin: contactCenter(m, n.fixed, n.moving) };
}

export function draftProblem(d: JointDraft): string | null {
  if (!d.fixed) return "Pick the fixed part.";
  if (!d.moving) return "Pick the moving part.";
  if (d.fixed === d.moving) return "Pick two different links.";
  if (!d.motion) return "Choose how the joint moves.";
  if (!d.origin) return "Click a feature to place the joint origin.";
  if (d.motion !== "rigid" && !d.axis) return "Click a round or flat face to set the axis.";
  if ((d.motion === "revolute" && !d.noLimits) || d.motion === "slider") {
    if (d.lower === null || d.upper === null) return "Set both limits.";
    if (d.lower > d.upper) return "The lower limit must not be above the upper limit.";
  }
  return null;
}

/** Only call when draftProblem(d) is null. */
export function draftToJoint(d: JointDraft): Joint {
  const type = jointType(d)!;
  const limited = type === "revolute" || type === "prismatic";
  return { id: d.id, parent_link_id: d.fixed!, child_link_id: d.moving!, type, origin_xyz: d.origin!,
    origin_rpy: [0, 0, 0], axis: d.axis, limit_lower: limited ? d.lower : null,
    limit_upper: limited ? d.upper : null, source: d.source === "suggested" ? "confirmed" : d.source };
}

/** A joint to draw while the draft is incomplete; null until both parts and an origin exist. */
export function draftPreviewJoint(d: JointDraft): Joint | null {
  if (!d.fixed || !d.moving || !d.origin) return null;
  return { id: d.id, parent_link_id: d.fixed, child_link_id: d.moving, type: jointType(d) ?? "fixed",
    origin_xyz: d.origin, origin_rpy: [0, 0, 0], axis: d.axis, limit_lower: d.lower, limit_upper: d.upper,
    source: d.source };
}

/** Snap point under a clicked triangle: a round face gives its axis line, a flat face its normal. */
export function snapAt(body: Body, triangle: number): { origin: Vec3; axis: Vec3; kind: "cylinder" | "plane" } | null {
  const f = body.faces.find((x) => x.triangle_indices.includes(triangle));
  if (!f) return null;
  if (f.kind === "cylinder" && f.axis) return { kind: "cylinder", origin: f.center, axis: f.axis };
  if (f.kind === "plane" && f.normal) {
    const t = body.triangles[triangle];
    if (!t) return null;
    const [a, b, c] = t.map((i) => body.vertices[i]);
    // plane centres can be any point on the plane, so use where the user clicked
    return { kind: "plane", origin: [0, 1, 2].map((k) => (a[k] + b[k] + c[k]) / 3) as Vec3, axis: f.normal };
  }
  return null;
}
```

```ts
import type { Vec3 } from "../api/types";

export type ViewName = "front" | "back" | "left" | "right" | "top" | "iso";

/** Unit vector from the target towards the camera (z is up). */
export function viewDirection(v: ViewName): Vec3 {
  switch (v) {
    case "front": return [0, -1, 0];
    case "back": return [0, 1, 0];
    case "left": return [-1, 0, 0];
    case "right": return [1, 0, 0];
    case "top": { const t = 1e-3; const l = Math.hypot(t, 1); return [0, -t / l, 1 / l]; }
    case "iso": { const s = 1 / Math.sqrt(3); return [s, -s, s]; }
  }
}

/** Camera distance that fits a sphere of this radius in the view, with a margin. */
export function fitDistance(radius: number, fovDeg: number): number {
  return ((radius || 0.5) / Math.sin(((fovDeg / 2) * Math.PI) / 180)) * 1.15;
}
```

```ts
import {
  ArrowHelper, Box3, BufferAttribute, BufferGeometry, DirectionalLight, EdgesGeometry, GridHelper, Group,
  HemisphereLight, LineBasicMaterial, LineSegments, Material, Matrix4, Mesh, MeshStandardMaterial, Object3D,

import { OrbitControls } from "three/examples/jsm/controls/OrbitControls.js";
import { TransformControls } from "three/examples/jsm/controls/TransformControls.js";
import type { Body, Joint, Vec3 } from "../api/types";
import { bodyArrays, isClick } from "./meshData";
import { fitDistance, viewDirection, type ViewName } from "./viewMath";

export type Hit = { bodyId: string; triangle: number } | null;
type PickCb = (hit: Hit, additive: boolean) => void;

export const PART_COLOR = 0xb9bdc3;
const SELECT_EMISSIVE = 0x1d4ed8;
const HOVER_EMISSIVE = 0x475569;

export class Viewer {

  private scene = new Scene();
  private camera = new PerspectiveCamera(45, 1, 0.001, 1000);
  private controls: OrbitControls;

  private grid: GridHelper | null = null;
  private bounds = new Sphere(new Vector3(), 0.5);
  private pickCb: PickCb = () => {};
  private hoverCb: ((hit: Hit) => void) | null = null;
  private cameraCbs = new Set<() => void>();
  private frame = 0;
  private dirty = true;
  private framed = false;
  private observer: ResizeObserver;
  private selection: string[] = [];
  private hovered: string | null = null;
  private tints: Record<string, number> = {};
  private preview: { ids: string[]; m: Matrix4 | null } = { ids: [], m: null };
  private ignored = new Set<string>();
  private down: { x: number; y: number } | null = null;

  // legacy (old UI) — removed in Task 6
  private joints = new Group();

  private gizmoTarget = new Object3D();

  constructor(private container: HTMLElement) {
    this.renderer = new WebGLRenderer({ antialias: true, alpha: true });
    this.renderer.setClearColor(0x000000, 0);
    this.renderer.setPixelRatio(window.devicePixelRatio);
    container.appendChild(this.renderer.domElement);
    this.scene.add(new HemisphereLight(0xffffff, 0x8a8f99, 0.9));
    const key = new DirectionalLight(0xffffff, 1.1);
    key.position.set(3, -4, 6);

    this.camera.position.set(2, -2, 1.5);
    this.controls = new OrbitControls(this.camera, this.renderer.domElement);
    this.controls.addEventListener("change", this.requestRender);
    this.gizmo = new TransformControls(this.camera, this.renderer.domElement);
    this.gizmo.addEventListener("dragging-changed", (e) => { this.controls.enabled = !e.value; });
    this.gizmo.addEventListener("change", this.requestRender);
    const el = this.renderer.domElement;
    el.addEventListener("pointerdown", this.onDown);
    el.addEventListener("pointermove", this.onMove);
    el.addEventListener("pointerup", this.onUp);
    this.observer = new ResizeObserver(() => this.resize());
    this.observer.observe(container);
    this.resize();
    const loop = () => {
      if (this.pendingHover) {
        const e = this.pendingHover;
        this.pendingHover = null;
        this.hover(e);
      }
      if (this.dirty) {
        this.dirty = false;
        this.renderer.render(this.scene, this.camera);
        this.cameraCbs.forEach((cb) => cb());
      }
      this.frame = requestAnimationFrame(loop);
    };
    loop();

  /** Draw on the next frame. Nothing is drawn while nothing changes. */
  requestRender = () => { this.dirty = true; };

  private resize() {
    const { clientWidth: w, clientHeight: h } = this.container;
    this.renderer.setSize(w, h);
    this.camera.aspect = w / Math.max(h, 1);
    this.camera.updateProjectionMatrix();
    this.requestRender();

  setBodies(bodies: Body[], ignored: Set<string>) {
    this.ignored = ignored;
    const keep = new Set(bodies.map((b) => b.id));
    for (const [id, m] of this.meshes) {
      if (!keep.has(id)) { this.scene.remove(m); this.free(m); this.meshes.delete(id); }
    }
    for (const b of bodies) {
      const old = this.meshes.get(b.id);
      if (old && old.userData.source === b) continue;
      if (old) { this.scene.remove(old); this.free(old); }
      const { positions, indices } = bodyArrays(b);
      const g = new BufferGeometry();

      g.setIndex(new BufferAttribute(indices, 1));
      g.computeVertexNormals();

      const edges = new LineSegments(new EdgesGeometry(g, 25), this.edgeMaterial);
      edges.name = "edges";
      mesh.add(edges);
      mesh.userData = { bodyId: b.id, source: b };
      this.scene.add(mesh);
      this.meshes.set(b.id, mesh);
    }
    this.computeBounds();
    if (!this.framed && this.meshes.size) { this.setView("home"); this.framed = true; }
    this.applyLooks();
    this.setPreview(this.preview.ids, this.preview.m);

  private free(m: Mesh) {
    m.geometry.dispose();
    (m.material as Material).dispose();
    for (const c of m.children) {
      if (c.name === "edges") (c as LineSegments).geometry.dispose();
      if (c.name === "approx") ((c as Mesh).material as Material).dispose();
    }
  }

  private computeBounds() {
    const b = new Box3();
    for (const m of this.meshes.values()) if (!this.ignored.has(m.userData.bodyId)) b.expandByObject(m);
    if (b.isEmpty()) return;
    b.getBoundingSphere(this.bounds);
    if (this.grid) {
      this.scene.remove(this.grid);
      this.grid.geometry.dispose();
      (this.grid.material as Material).dispose();
    }
    this.grid = new GridHelper(this.bounds.radius * 4, 20, 0x9aa1ab, 0xc4c9d0);
    this.grid.rotateX(Math.PI / 2);
    this.grid.position.set(this.bounds.center.x, this.bounds.center.y, b.min.z);
    const gm = this.grid.material as Material;
    gm.transparent = true;
    gm.opacity = 0.5;
    this.scene.add(this.grid);
  }

  private applyLooks() {
    for (const [id, m] of this.meshes) {
      const mat = m.material as MeshStandardMaterial;
      mat.color.setHex(this.tints[id] ?? PART_COLOR);
      const ignored = this.ignored.has(id);
      mat.transparent = ignored;
      mat.opacity = ignored ? 0.15 : 1;
      mat.depthWrite = !ignored;
      const sel = this.selection.includes(id);
      mat.emissive.setHex(sel ? SELECT_EMISSIVE : id === this.hovered ? HOVER_EMISSIVE : 0x000000);
      mat.emissiveIntensity = sel ? 0.45 : 0.25;
    }
    this.requestRender();
  }

  setSelection(bodyIds: string[]) { this.selection = bodyIds; this.applyLooks(); }

  setTints(t: Record<string, number>) { this.tints = t; this.applyLooks(); }

  setPreview(bodyIds: string[], m: Matrix4 | null) {
    this.preview = { ids: bodyIds, m };
    for (const [id, mesh] of this.meshes) {
      mesh.matrixAutoUpdate = false;
      mesh.matrix.copy(m && bodyIds.includes(id) ? m : new Matrix4());
      mesh.matrixWorldNeedsUpdate = true;
    }
    this.requestRender();
  }

  setView(v: ViewName | "home") {
    this.computeBounds();
    const dir = new Vector3(...viewDirection(v === "home" ? "iso" : v));
    const d = fitDistance(this.bounds.radius, this.camera.fov);
    this.camera.position.copy(this.bounds.center).addScaledVector(dir, d);
    this.camera.near = d / 1000;
    this.camera.far = d * 100;
    this.camera.updateProjectionMatrix();
    this.controls.target.copy(this.bounds.center);
    this.controls.update();
    this.requestRender();
  }

  focus(bodyIds: string[]) {
    const b = new Box3();
    for (const id of bodyIds) { const m = this.meshes.get(id); if (m) b.expandByObject(m); }
    if (b.isEmpty()) { this.setView("home"); return; }
    const s = new Sphere();
    b.getBoundingSphere(s);
    const dir = this.camera.position.clone().sub(this.controls.target).normalize();
    this.controls.target.copy(s.center);
    this.camera.position.copy(s.center).addScaledVector(dir, fitDistance(s.radius, this.camera.fov));
    this.controls.update();
    this.requestRender();
  }

  screenPoint(p: Vec3): { x: number; y: number } | null {
    const v = new Vector3(...p).project(this.camera);
    if (v.z < -1 || v.z > 1) return null;
    const { clientWidth: w, clientHeight: h } = this.container;
    return { x: ((v.x + 1) / 2) * w, y: ((1 - v.y) / 2) * h };
  }

  onCameraChange(cb: () => void): () => void {
    this.cameraCbs.add(cb);
    return () => { this.cameraCbs.delete(cb); };
  }

  onPick(cb: PickCb) { this.pickCb = cb; }

  onHover(cb: ((hit: Hit) => void) | null) {
    this.hoverCb = cb;
    if (!cb && this.hovered) { this.hovered = null; this.applyLooks(); }
  }

  private ray(e: { clientX: number; clientY: number }): Raycaster {
    const r = this.renderer.domElement.getBoundingClientRect();
    const ray = new Raycaster();
    ray.setFromCamera(new Vector2(((e.clientX - r.left) / r.width) * 2 - 1,
      -((e.clientY - r.top) / r.height) * 2 + 1), this.camera);
    return ray;
  }

  private hitBody(ray: Raycaster): Hit {
    const meshes = [...this.meshes.values()].filter((m) => !this.ignored.has(m.userData.bodyId));
    const i = ray.intersectObjects(meshes, false)[0];
    return i ? { bodyId: i.object.userData.bodyId, triangle: i.faceIndex ?? -1 } : null;
  }

  private hover(e: PointerEvent) {
    const hit = this.hitBody(this.ray(e));
    const id = hit?.bodyId ?? null;
    if (id !== this.hovered) { this.hovered = id; this.applyLooks(); }
    this.hoverCb?.(hit);
  }

  private onDown = (e: PointerEvent) => { this.down = { x: e.clientX, y: e.clientY }; };

  private onMove = (e: PointerEvent) => {
    if (this.hoverCb && !this.down) this.pendingHover = e;
  };

  private onUp = (e: PointerEvent) => {
    const down = this.down;
    this.down = null;
    if (this.gizmo.dragging || !down || !isClick(down, { x: e.clientX, y: e.clientY })) return;
    this.pickCb(this.hitBody(this.ray(e)), e.shiftKey);
  };

  // ---- legacy (old UI) — removed in Task 6 ----
  private clearJoints() {
    for (const a of this.joints.children) (a as ArrowHelper).dispose();
    this.joints.clear();
  }

  setJoints(items: { joint: Joint; dashed: boolean }[]) {
    this.clearJoints();
    for (const { joint, dashed } of items) {
      if (!joint.axis) continue;
      this.joints.add(new ArrowHelper(new Vector3(...joint.axis).normalize(), new Vector3(...joint.origin_xyz),
        0.1, dashed ? 0x999999 : 0x1565c0));
    }
    this.requestRender();
  }

  attachGizmo(origin: Vec3, axis: Vec3, onChange: (origin: Vec3, axis: Vec3) => void) {
    this.gizmoTarget.position.set(...origin);
    this.gizmoTarget.quaternion.setFromUnitVectors(new Vector3(0, 0, 1), new Vector3(...axis).normalize());
    this.gizmo.attach(this.gizmoTarget);
    this.scene.add(this.gizmo.getHelper());
    this.gizmo.removeEventListener("objectChange", this.gizmoChange);
    this.gizmoChange = () => {
      const p = this.gizmoTarget.position;
      const a = new Vector3(0, 0, 1).applyQuaternion(this.gizmoTarget.quaternion);
      onChange([p.x, p.y, p.z], [a.x, a.y, a.z]);
    };
    this.gizmo.addEventListener("objectChange", this.gizmoChange);
    this.requestRender();
  }
  private gizmoChange = () => {};

  setGizmoMode(mode: "translate" | "rotate") { this.gizmo.setMode(mode); }

  detachGizmo() {
    this.gizmo.detach();
    this.scene.remove(this.gizmo.getHelper());
    this.requestRender();
  }
  // ---- end legacy ----

  dispose() {
    cancelAnimationFrame(this.frame);
    const el = this.renderer.domElement;
    el.removeEventListener("pointerdown", this.onDown);
    el.removeEventListener("pointermove", this.onMove);
    el.removeEventListener("pointerup", this.onUp);
    this.observer.disconnect();
    this.cameraCbs.clear();
    this.clearJoints();
    this.controls.dispose();
    this.gizmo.dispose();
    for (const m of this.meshes.values()) this.free(m);
    this.edgeMaterial.dispose();
    if (this.grid) { this.grid.geometry.dispose(); (this.grid.material as Material).dispose(); }
    this.renderer.forceContextLoss();
    this.renderer.dispose();
    el.remove();
  }
}
```

```ts
  ArrowHelper, BufferGeometry, Group, Line, LineBasicMaterial, LineDashedMaterial, Material, Mesh, MeshBasicMaterial,
  Object3D, OctahedronGeometry, SphereGeometry, Vector3,
} from "three";
import type { Joint, Vec3 } from "../api/types";

export interface JointGlyph { joint: Joint; state: "done" | "suggested" | "active" }
export const GLYPH_COLORS = { done: 0x3f4349, suggested: 0x6b7280, active: 0x2563eb } as const;
const HANDLE = { lower: 0x2563eb, upper: 0xf59e0b } as const;

const sub = (a: Vec3, b: Vec3): Vec3 => [a[0] - b[0], a[1] - b[1], a[2] - b[2]];
const dot = (a: Vec3, b: Vec3) => a[0] * b[0] + a[1] * b[1] + a[2] * b[2];
const cross = (a: Vec3, b: Vec3): Vec3 => [a[1] * b[2] - a[2] * b[1], a[2] * b[0] - a[0] * b[2], a[0] * b[1] - a[1] * b[0]];
const norm = (a: Vec3): Vec3 => { const l = Math.hypot(...a) || 1; return [a[0] / l, a[1] / l, a[2] / l]; };
const add = (a: Vec3, b: Vec3, s = 1): Vec3 => [a[0] + b[0] * s, a[1] + b[1] * s, a[2] + b[2] * s];
const v3 = (p: Vec3) => new Vector3(...p);

/** Unit vector at right angles to the axis: the 0° direction for arcs and angles. */
export function perpendicular(axis: Vec3): Vec3 {
  const a = norm(axis);
  const helper: Vec3 = Math.abs(a[2]) < 0.9 ? [0, 0, 1] : [1, 0, 0];
  return norm(cross(helper, a));
}

export function arcPoints(origin: Vec3, axis: Vec3, radius: number, from: number, to: number, segments = 48): Vec3[] {
  const a = norm(axis), u = perpendicular(a), v = cross(a, u);
  return Array.from({ length: segments + 1 }, (_, i) => {
    const t = from + ((to - from) * i) / segments;
    return add(add(origin, u, radius * Math.cos(t)), v, radius * Math.sin(t));
  });
}

/** Signed angle of p around the axis, measured from perpendicular(axis), in (−π, π]. */
export function angleAroundAxis(p: Vec3, origin: Vec3, axis: Vec3): number {
  const a = norm(axis), u = perpendicular(a), v = cross(a, u), d = sub(p, origin);
  return Math.atan2(dot(d, v), dot(d, u));
}

export function rayPlaneHit(ro: Vec3, rd: Vec3, origin: Vec3, normal: Vec3): Vec3 | null {
  const denom = dot(rd, normal);
  if (Math.abs(denom) < 1e-9) return null;
  const t = dot(sub(origin, ro), normal) / denom;
  return t < 0 ? null : add(ro, rd, t);
}

/** Position along the axis line of the point closest to the ray. */
export function closestParamOnAxis(ro: Vec3, rd: Vec3, origin: Vec3, axis: Vec3): number {
  const a = norm(axis), d = norm(rd), w = sub(origin, ro);
  const b = dot(a, d), denom = 1 - b * b;
  if (denom < 1e-9) return 0;
  return (b * dot(w, d) - dot(w, a)) / denom;
}

function line(points: Vec3[], color: number): Line {
  return new Line(new BufferGeometry().setFromPoints(points.map(v3)), new LineBasicMaterial({ color }));
}

function ball(at: Vec3, r: number, color: number, handle?: "lower" | "upper"): Mesh {
  const m = new Mesh(new SphereGeometry(r, 16, 12), new MeshBasicMaterial({ color }));
  m.position.set(...at);
  if (handle) m.userData.handle = handle;
  return m;
}

export function buildGlyph(g: JointGlyph, size: number): Group {
  const { joint: j, state } = g;
  const color = GLYPH_COLORS[state];
  const grp = new Group();
  const o = j.origin_xyz;
  grp.add(ball(o, size * 0.035, color));
  if (j.type === "fixed" || !j.axis) {
    const m = new Mesh(new OctahedronGeometry(size * 0.08), new MeshBasicMaterial({ color }));
    m.position.set(...o);
    grp.add(m);
  } else {
    const a = norm(j.axis);
    const active = state === "active";
    grp.add(new ArrowHelper(v3(a), v3(add(o, a, -size * 0.5)), size, color, size * 0.15, size * 0.08));
    if (j.type === "revolute" || j.type === "continuous" || j.type === "cylindrical") {
      const limited = j.type === "revolute" && j.limit_lower !== null && j.limit_upper !== null;
      const [lo, hi] = limited ? [j.limit_lower!, j.limit_upper!] : [-Math.PI, Math.PI];
      const r = size * 0.45;
      grp.add(line(arcPoints(o, a, r, lo, hi), color));
      if (active && limited) {
        grp.add(ball(arcPoints(o, a, r, lo, lo, 1)[0], size * 0.06, HANDLE.lower, "lower"));
        grp.add(ball(arcPoints(o, a, r, hi, hi, 1)[0], size * 0.06, HANDLE.upper, "upper"));
      }
    } else if (j.type === "prismatic") {
      const lo = j.limit_lower ?? 0, hi = j.limit_upper ?? 0;
      grp.add(line([add(o, a, lo), add(o, a, hi)], color));
      if (active) {
        grp.add(ball(add(o, a, lo), size * 0.06, HANDLE.lower, "lower"));
        grp.add(ball(add(o, a, hi), size * 0.06, HANDLE.upper, "upper"));
      }
    } else if (j.type === "planar") {
      grp.add(line(arcPoints(o, a, size * 0.4, Math.PI / 4, Math.PI / 4 + 2 * Math.PI, 4), color));
    }
  }
  if (state === "suggested") {
    grp.traverse((c) => {
      const mat = (c as Mesh).material as Material | undefined;
      if (mat) { mat.transparent = true; mat.opacity = 0.55; }
    });
  }
  return grp;
}

export function buildSnap(s: { origin: Vec3; axis: Vec3 }, size: number): Group {
  const g = new Group();
  const c = GLYPH_COLORS.active;
  const a = norm(s.axis);
  g.add(line(arcPoints(s.origin, a, size * 0.2, 0, 2 * Math.PI), c));
  g.add(line([add(s.origin, a, -size * 0.6), add(s.origin, a, size * 0.6)], c));
  g.add(ball(s.origin, size * 0.035, c));
  return g;
}

export function buildLooseLine(a: Vec3, b: Vec3, size: number): Line {
  const l = new Line(new BufferGeometry().setFromPoints([v3(a), v3(b)]),
    new LineDashedMaterial({ color: 0xdc2626, dashSize: size * 0.08, gapSize: size * 0.05 }));
  l.computeLineDistances();
  return l;
}

export function disposeTree(o: Object3D) {
  o.traverse((c) => {
    const m = c as Mesh;
    m.geometry?.dispose();
    const mat = m.material as Material | Material[] | undefined;
    if (Array.isArray(mat)) mat.forEach((x) => x.dispose());
    else mat?.dispose();
  });
}
```

```ts
import { contactCenter, snapAt, type JointDraft } from "../model/jointDraft";
import type { Action } from "../model/reducer";
import type { ModelState } from "../model/types";
import type { Hit } from "../viewer/Viewer";
import type { PickMode } from "./ctx";
import type { Selection } from "./selection";

export interface PickResult { selection?: Selection; draft?: JointDraft; action?: Action; mode?: PickMode }

/** What a click in the 3D view does, by pick mode. Empty space never leaves a pick mode. */
export function routePick(mode: PickMode, hit: Hit, additive: boolean, m: ModelState, selection: Selection,
  draft: JointDraft | null): PickResult {
  if (mode === "select") {
    if (!hit) return { selection: null };
    const prev = additive && selection?.kind === "bodies" ? selection.ids : [];
    return { selection: { kind: "bodies", ids: [...new Set([...prev, hit.bodyId])] } };
  }
  const link = hit ? m.links.find((l) => l.body_ids.includes(hit.bodyId)) : undefined;
  if (!hit || !link) return {};
  if (mode === "base") return { action: { type: "setRoot", linkId: link.id }, mode: "select" };
  if (!draft) return { mode: "select" };
  if (mode === "fixed" || mode === "moving") {
    const next: JointDraft = { ...draft, [mode]: link.id };
    if (next.fixed && next.moving && next.fixed !== next.moving && !next.origin) {
      next.origin = contactCenter(m, next.fixed, next.moving);
    }
    return { draft: next, mode: mode === "fixed" && !next.moving ? "moving" : "select" };
  }
  const snap = snapAt(m.bodies[hit.bodyId], hit.triangle);
  return snap ? { draft: { ...draft, origin: snap.origin, axis: snap.axis }, mode: "select" } : {};
}
```

```ts
import type { Vec3 } from "../api/types";
import type { StepId } from "../model/checklist";
import { bodyBox, linkBox, type Box } from "../model/geometry";
import { chainDepth } from "../model/nextJoint";
import { touchingPairs } from "../model/pairs";
import { partProblems } from "../model/problems";
import type { ModelState } from "../model/types";
import type { Selection } from "./selection";

export interface Marker { id: string; at: Vec3; kind: "problem" | "joint" | "loose"; label: string; target: Selection }

const top = (b: Box): Vec3 => [(b.min[0] + b.max[0]) / 2, (b.min[1] + b.max[1]) / 2, b.max[2]];
const mid = (b: Box): Vec3 => [0, 1, 2].map((i) => (b.min[i] + b.max[i]) / 2) as Vec3;

export function markersFor(step: StepId, m: ModelState): Marker[] {
  const out: Marker[] = [];
  const name = (id: string) => m.links.find((l) => l.id === id)?.name ?? id;
  const pinned = new Set<string>();
  for (const p of partProblems(m)) {
    if (p.kind === "failed" || pinned.has(p.bodyId)) continue;   // failed parts have no geometry to pin to
    const b = bodyBox(m.bodies[p.bodyId]);
    if (!b) continue;
    pinned.add(p.bodyId);
    out.push({ id: `problem-${p.bodyId}`, at: top(b), kind: "problem",
      label: p.kind === "approximate" ? "Approximate shape" : p.warning.message, target: { kind: "bodies", ids: [p.bodyId] } });
  }
  if (step === "connect" || step === "export") {
    for (const j of m.joints) {
      out.push({ id: `joint-${j.id}`, at: j.origin_xyz, kind: "joint",
        label: `${name(j.parent_link_id)} → ${name(j.child_link_id)}`, target: { kind: "joint", id: j.id } });
    }
  }
  if (step === "connect" && m.rootLinkId) {
    const depth = chainDepth(m);
    for (const l of m.links) {
      if (depth.has(l.id)) continue;
      const b = linkBox(l, m.bodies);
      if (b) out.push({ id: `loose-${l.id}`, at: top(b), kind: "loose", label: "Not connected", target: { kind: "link", id: l.id } });
    }
  }
  return out;
}

/** One dashed line per loose link, to a touching link that is already connected. */
export function looseLines(m: ModelState): [Vec3, Vec3][] {
  if (!m.rootLinkId) return [];
  const depth = chainDepth(m);
  const done = new Set<string>();
  const out: [Vec3, Vec3][] = [];
  for (const [a, b] of touchingPairs(m.links, m.bodies)) {
    const inA = depth.has(a.id), inB = depth.has(b.id);
    if (inA === inB) continue;
    const [inside, loose] = inA ? [a, b] : [b, a];
    if (done.has(loose.id)) continue;
    const A = linkBox(inside, m.bodies), B = linkBox(loose, m.bodies);
    if (A && B) { out.push([mid(A), mid(B)]); done.add(loose.id); }
  }
  return out;
}
```

```ts
export type Shortcut = "undo" | "redo" | "joint" | "group" | "animate" | "focus" | "back";

type KeyLike = Pick<KeyboardEvent, "key" | "ctrlKey" | "metaKey" | "shiftKey"> & { target: EventTarget | null };

const PLAIN: Record<string, Shortcut> = { j: "joint", g: "group", " ": "animate", f: "focus", escape: "back" };

export function shortcutFor(e: KeyLike): Shortcut | null {
  const k = e.key.toLowerCase();
  const t = e.target as HTMLElement | null;
  const typing = !!t && (t.tagName === "INPUT" || t.tagName === "TEXTAREA" || t.tagName === "SELECT" || t.isContentEditable);
  if (typing) return k === "escape" ? "back" : null;
  if (e.ctrlKey || e.metaKey) {
    if (k === "z") return e.shiftKey ? "redo" : "undo";
    if (k === "y") return "redo";
    return null;
  }
  return PLAIN[k] ?? null;
}
```

```tsx
import { useCallback, useEffect, useMemo, useReducer, useRef, useState } from "react";
import { detectJoints } from "./api/client";
import type { StepId } from "./model/checklist";
import { DetectionRunner, pairsToDetect, type Progress } from "./model/detection";
import { historyReducer, initialHistory } from "./model/history";
import { draftForPair, emptyDraft, snapAt, type JointDraft } from "./model/jointDraft";
import { nextJoint } from "./model/nextJoint";
import { partProblems } from "./model/problems";
import Banner from "./ui/Banner";
import Browser from "./ui/Browser";
import { glyphsFor, tintsFor } from "./ui/colors";
import type { Ctx, PickMode } from "./ui/ctx";
import MarkerLayer from "./ui/MarkerLayer";
import { looseLines, markersFor, type Marker } from "./ui/markers";
import { routePick } from "./ui/pick";
import { linksOfSelection, selectedBodies, type Selection } from "./ui/selection";
import { shortcutFor } from "./ui/shortcuts";
import StepPanel from "./ui/steps/StepPanel";
import Stepper from "./ui/Stepper";
import ViewCube from "./ui/ViewCube";
import ViewerPane from "./ui/ViewerPane";
import type { Hit, Viewer } from "./viewer/Viewer";

export default function App() {
  const [history, dispatch] = useReducer(historyReducer, undefined, initialHistory);
  const model = history.present;
  const [step, goTo] = useState<StepId>("parts");
  const [selection, setSelection] = useState<Selection>(null);
  const [pick, setPick] = useState<PickMode>("select");
  const [jointDraft, setJointDraft] = useState<JointDraft | null>(null);
  const [banner, notify] = useState<string | null>(null);
  const [progress, setProgress] = useState<Progress>({ done: 0, total: 0, running: false, paused: false });
  const [robotName, setRobotName] = useState("robot");
  const [scale, setScale] = useState(0.001);
  const [viewer, setViewer] = useState<Viewer | null>(null);
  const [autoGrouped, setAutoGrouped] = useState(false);

  const runner = useRef<DetectionRunner>();
  if (!runner.current) {
    runner.current = new DetectionRunner(
      (a, b, la, lb, signal) => detectJoints(a, b, la, lb, signal),
      {
        onResult: (p, result) => dispatch({ type: "setSuggestion", suggestion: { ...p, result, status: "review" } }),
        onProgress: setProgress,
        onError: (m) => notify(`Joint detection paused: ${m}`),
      });
  }
  useEffect(() => {
    runner.current!.update(pairsToDetect(model), (linkId) =>
      (model.links.find((l) => l.id === linkId)?.body_ids ?? []).map((id) => model.bodies[id]));
  }, [model]);

  // the viewer calls back outside React's render: read the latest state through a ref
  const live = useRef({ pick, model, selection, jointDraft, viewer });
  live.current = { pick, model, selection, jointDraft, viewer };

  const onPick = useCallback((hit: Hit, additive: boolean) => {
    const s = live.current;
    const r = routePick(s.pick, hit, additive, s.model, s.selection, s.jointDraft);
    if (r.selection !== undefined) setSelection(r.selection);
    if (r.draft) setJointDraft(r.draft);
    if (r.action) dispatch(r.action);
    if (r.mode) setPick(r.mode);
  }, []);

  useEffect(() => {
    if (!viewer) return;
    if (pick === "origin") {
      viewer.onHover((hit) => {
        const b = hit ? live.current.model.bodies[hit.bodyId] : undefined;
        viewer.setSnap(b && hit ? snapAt(b, hit.triangle) : null);
      });
    } else {
      viewer.onHover(null);
      viewer.setSnap(null);
    }
  }, [viewer, pick]);

  const drafting = jointDraft !== null;
  useEffect(() => {
    viewer?.onLimitDrag(drafting ? (which, value) => setJointDraft((d) => (d ? { ...d, [which]: value } : d)) : null);
  }, [viewer, drafting]);

  useEffect(() => {
    if (step !== "connect") { setJointDraft(null); setPick("select"); viewer?.setPreview([], null); }
  }, [step, viewer]);

  useEffect(() => {
    const onKey = (e: KeyboardEvent) => {
      const s = shortcutFor(e);
      if (!s) return;
      e.preventDefault();
      const cur = live.current;
      if (s === "undo") dispatch({ type: "undo" });
      else if (s === "redo") dispatch({ type: "redo" });
      else if (s === "joint") { goTo("connect"); setJointDraft((d) => d ?? emptyDraft()); setPick("fixed"); }
      else if (s === "group") {
        const ids = linksOfSelection(cur.model, cur.selection);
        if (ids.length > 1) dispatch({ type: "merge", linkIds: ids });
      } else if (s === "focus") cur.viewer?.focus(selectedBodies(cur.model, cur.selection));
      else if (s === "animate") window.dispatchEvent(new Event("cad:animate"));
      else if (cur.pick !== "select") setPick("select");
      else if (cur.jointDraft) { setJointDraft(null); cur.viewer?.setPreview([], null); }
      else setSelection(null);
    };
    window.addEventListener("keydown", onKey);
    return () => window.removeEventListener("keydown", onKey);
  }, []);

  const bodies = useMemo(() => Object.values(model.bodies), [model.bodies]);
  const selected = useMemo(() => selectedBodies(model, selection), [model, selection]);
  const tints = useMemo(() => tintsFor(step, model, jointDraft), [step, model, jointDraft]);
  const glyphs = useMemo(() => glyphsFor(step, model, jointDraft), [step, model, jointDraft]);
  const markers = useMemo(() => markersFor(step, model), [step, model]);
  const loose = useMemo(() => (step === "connect" ? looseLines(model) : []), [step, model]);
  const approximate = useMemo(() => partProblems(model).filter((p) => p.kind === "approximate").map((p) => p.bodyId), [model]);

  const onMarker = (mk: Marker) => {
    if (mk.kind === "loose" && mk.target?.kind === "link") {
      const n = nextJoint(model, mk.target.id);
      if (n) { setJointDraft(draftForPair(model, n)); return; }
    }
    setSelection(mk.target);
    if (mk.kind === "problem") goTo("parts");
  };

  const ctx: Ctx = { model, dispatch, canUndo: history.past.length > 0, canRedo: history.future.length > 0, step,
    goTo, selection, setSelection, pick, setPick, jointDraft, setJointDraft, viewer, notify, scale, setScale,
    robotName, setRobotName, autoGrouped, setAutoGrouped, detecting: progress.running };

  return (
    <div className="app">
      <Stepper ctx={ctx} progress={progress} onCancel={() => runner.current!.cancel()} onResume={() => runner.current!.resume()} />
      <Banner message={banner} onClose={() => notify(null)} />
      <div className="workspace">
        <aside className="panel left"><Browser ctx={ctx} /></aside>
        <main className={`viewport${pick !== "select" ? " picking" : ""}`}>
          <ViewerPane bodies={bodies} ignored={model.ignored} selected={selected} tints={tints}
            approximate={approximate} glyphs={glyphs} loose={loose} onPick={onPick} onViewer={setViewer} />
          <MarkerLayer viewer={viewer} markers={markers} onClick={onMarker} />
          <ViewCube viewer={viewer} />
        </main>
        <aside className="panel right"><StepPanel ctx={ctx} /></aside>
      </div>
    </div>
  );
}
```

```ts
import { useEffect, useRef, useState } from "react";
import { linkMass } from "../api/client";
import type { Body, Link, LinkMass } from "../api/types";

/** Backend messages name links by id; show their names instead. */
export function withNames(message: string, links: Link[]): string {
  return message.replace(/[Ll]ink '([^']+)'/g, (all, id: string) => {
    const l = links.find((x) => x.id === id);
    return l ? `Link "${l.name}"` : all;
  });
}

export function useLinkMass(link: Link | undefined, bodies: Record<string, Body>, links: Link[]) {
  const [state, setState] = useState<{ mass: LinkMass | null; error: string | null }>({ mass: null, error: null });
  const names = useRef(links);
  names.current = links;
  useEffect(() => {
    setState({ mass: null, error: null });
    if (!link) return;
    let alive = true;
    const t = setTimeout(() => {
      linkMass(link, link.body_ids.map((id) => bodies[id]))
        .then((mass) => { if (alive) setState({ mass, error: null }); })
        .catch((e) => { if (alive) setState({ mass: null, error: withNames((e as Error).message, names.current) }); });
    }, 300);
    return () => { alive = false; clearTimeout(t); };
  }, [link, bodies]);
  return state;
}
```

```tsx
import { Check, Download, Play, X } from "lucide-react";
import { useState } from "react";
import type { Joint } from "../../api/types";
import { exportRobot } from "../../api/client";
import { exportChecklist, type CheckItem } from "../../model/checklist";
import { splitExportError } from "../../model/errors";
import { buildExportRequest } from "../../model/exportRequest";
import { NAME_RE } from "../../model/types";
import { jointMotion, previewRange, subtreeLinks } from "../../viewer/preview";
import type { Viewer } from "../../viewer/Viewer";
import type { Ctx } from "../ctx";
import { downloadBlob } from "../download";
import Info from "../Info";
import { withNames } from "../useLinkMass";

/** One swing: rest → upper → rest → lower → rest, over 1.6 s. */
function swing(viewer: Viewer, j: Joint, bodyIds: string[], lo: number, hi: number): Promise<void> {
  return new Promise((done) => {
    const t0 = performance.now();
    const tick = (t: number) => {
      const k = Math.min(1, (t - t0) / 1600);
      const s = Math.sin(2 * Math.PI * k);
      viewer.setPreview(bodyIds, jointMotion(j, s >= 0 ? s * hi : -s * lo));
      if (k < 1) requestAnimationFrame(tick); else done();
    };
    requestAnimationFrame(tick);
  });
}

export default function ExportStep({ ctx }: { ctx: Ctx }) {
  const { model, robotName, setRobotName, goTo, setSelection, viewer, notify } = ctx;
  const [busy, setBusy] = useState(false);
  const [playing, setPlaying] = useState(false);
  const [server, setServer] = useState<string[]>([]);
  const items = exportChecklist(model, robotName);
  const req = buildExportRequest(model);
  const blocked = items.find((i) => !i.ok);
  const meshes = model.links.filter((l) => l.body_ids.length > 0).length;
  const linkName = (id: string) => model.links.find((l) => l.id === id)?.name ?? id;

  const open = (i: CheckItem) => {
    goTo(i.step);
    if (i.jointIds[0]) setSelection({ kind: "joint", id: i.jointIds[0] });
    else if (i.linkIds[0]) {
      setSelection({ kind: "link", id: i.linkIds[0] });
      viewer?.focus(model.links.find((l) => l.id === i.linkIds[0])?.body_ids ?? []);
    }
  };

  const onExport = async () => {
    setBusy(true);
    setServer([]);
    try {
      const { blob, warnings } = await exportRobot(robotName, req.links, req.joints, req.bodiesByLink);
      downloadBlob(blob, `${robotName}.zip`);
      notify(warnings.length ? `Exported with notes: ${warnings.map((w) => w.message).join(" ")}` : null);
    } catch (e) {
      const { byLink, byJoint, general } = splitExportError((e as Error).message);
      const label = (id: string) => {
        const j = req.joints.find((x) => x.id === id);
        return j ? `${linkName(j.parent_link_id)} → ${linkName(j.child_link_id)}: ` : "";
      };
      setServer([...Object.values(byLink).flat(),
        ...Object.entries(byJoint).flatMap(([id, ms]) => ms.map((m) => label(id) + m)),
        ...general].map((m) => withNames(m, model.links)));
    } finally {
      setBusy(false);
    }
  };

  const playAll = async () => {
    if (!viewer) return;
    setPlaying(true);
    for (const j of req.joints) {
      const [lo, hi] = previewRange(j);
      if (lo === hi) continue;
      const links = subtreeLinks(req.joints, j.id);
      await swing(viewer, j, model.links.filter((l) => links.includes(l.id)).flatMap((l) => l.body_ids), lo, hi);
    }
    viewer.setPreview([], null);
    setPlaying(false);
  };

  return (
    <section className="step">
      <h2>Export <Info term="urdf" /></h2>
      <p className="muted">Everything below must be ticked. Click an item to go and fix it.</p>
      <ul className="checklist">
        {items.map((i) => (
          <li key={i.id}>
            <button className={`check ${i.ok ? "ok" : "bad"}`} data-testid={`check-${i.id}`} disabled={i.ok} onClick={() => open(i)}>
              {i.ok ? <Check size={14} /> : <X size={14} />}
              <span><span>{i.label}</span>{!i.ok && i.detail && <span className="muted small block">{i.detail}</span>}</span>
            </button>
          </li>
        ))}
        {server.map((m, k) => (
          <li key={`server-${k}`}><div className="check bad" data-testid="server-error"><X size={14} /><span>{m}</span></div></li>
        ))}
      </ul>
      <button className="btn" data-testid="play-all" disabled={!viewer || playing || !req.joints.length} onClick={() => void playAll()}>
        <Play size={14} />{playing ? "Playing…" : "Play all joints"}
      </button>
      <div className="card">
        <div className="muted small" data-testid="summary">{model.links.length} links · {model.joints.length} joints · {meshes} meshes</div>
        <label className="row" style={{ margin: "6px 0" }}>Robot name <Info term="name" />
          <input className={`field${NAME_RE.test(robotName) ? "" : " invalid"}`} data-testid="robot-name" value={robotName}
            style={{ flex: 1 }} onChange={(e) => setRobotName(e.target.value)} />
        </label>
        <button className="btn btn-primary" data-testid="export" disabled={!!blocked || busy}
          title={blocked ? blocked.detail ?? blocked.label : ""} onClick={() => void onExport()}>
          <Download size={14} />{busy ? "Exporting…" : "Export URDF (.zip)"}
        </button>
      </div>
    </section>
  );
}
```
